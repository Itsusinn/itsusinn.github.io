# physics-simulation · 物理实验室

包含二维与三维三体、双摆、耦合弹簧和开普勒轨道的交互式物理实验室，使用 Rust / WASM、Bevy、WebGPU 和 egui。

正式发布时，CI 会将本页替换为完整的模拟应用。浏览器需要支持 WebGPU，并通过 HTTPS 访问。

- [查看源码与本地运行方法](https://github.com/Itsusinn/physics-simulation)
- 本地开发时，在 physics-simulation 项目中执行 `trunk serve --release`，打开 <http://127.0.0.1:8080/>。

网站本地构建显示此说明页，不会自动下载或编译 physics-simulation 项目。
